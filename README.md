# Undangan Pernikahan Digital — Gibran & Tiara

Tema: Islami Elegan / Minimalist Luxury / Cream & Gold.

## Jalankan
Buka `index.html` di browser, atau gunakan Live Server di VS Code.

## Isi yang sudah dibuat
- Cover premium + tombol Buka Undangan
- Hero utama
- Ayat Al-Qur'an
- Profil mempelai tanpa foto wajah
- Detail acara
- Countdown menuju 10 Januari 2030 pukul 09.00 WIB
- Galeri foto konsep tanpa wajah
- Kutipan untuk pembaca
- RSVP & ucapan tamu
- Tombol Google Maps
- Responsive untuk HP
- Data ucapan tersimpan di localStorage untuk demo

## Catatan RSVP
Agar RSVP dan ucapan benar-benar terlihat oleh semua tamu dari perangkat berbeda,
form perlu dihubungkan ke backend/database atau layanan form. Versi ini memakai
localStorage sehingga cocok sebagai prototype terlebih dahulu.

## Data acara
Gibran & Tiara
10 Januari 2030
09.00–17.00 WIB
Stadion Tangerang

### Urutan ucapan
Ucapan ditampilkan berdasarkan urutan masuk: komentar pertama muncul paling atas, komentar kedua di bawahnya, dan seterusnya.

**Catatan:** versi demo masih memakai `localStorage`, jadi data hanya tersimpan pada browser/perangkat yang mengirim komentar. Untuk undangan yang benar-benar dipakai banyak tamu, RSVP perlu database online agar semua tamu melihat komentar yang sama.
